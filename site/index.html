Postback lab: a recorded run and a signer

postback-tester sends signed test postbacks to a reward endpoint and checks what a single test postback cannot show: the retry that credits again, the reversal that is ignored, the forged request that is accepted. When this page was built, the example server of the repository ran once with a correct handler and once with a naive one, and the tool ran all {{CHECKS}} checks against each.
